# ♟️ Chess Game (SDL3)

A desktop Chess Game developed in **C** using **SDL3**, featuring an interactive graphical interface and complete chess gameplay. As one of my first programming projects, it allowed me to gain hands-on experience in graphics programming, event-driven application development, and implementing game logic using C.

---

## 📌 Overview

This project recreates the classic game of Chess with a clean graphical interface built using SDL3. Players can interact with the board using the mouse and play a complete game following standard chess rules.

The project focuses on combining programming logic with graphical rendering while providing an enjoyable user experience.

---

## ✨ Features

- ♟️ Interactive 8×8 chess board
- 🖱️ Mouse-based piece selection and movement
- 🎨 Graphical interface using SDL3
- 🖼️ Custom chess piece textures
- ✅ Legal move validation
- 🔄 Turn-based gameplay
- 🏁 Win detection (where implemented)
- ⚡ Smooth rendering and event handling

---

## 🛠️ Built With

- **Language:** C
- **Graphics Library:** SDL3-3.2.22
- **Image Library:** SDL3_image-devel-3.2.4-mingw
- **IDE:** Red Dev-C++

## 🚀 Getting Started

### Prerequisites

- Red Dev-C++ (or another C compiler)
- SDL3
- SDL3_image

### Installation

1. Clone the repository

```bash
git clone https://github.com/syed-abdullah-shah1/Chess-Game-SDL3-C.git
```

2. Open the project in Red Dev-C++.

3. Make sure SDL3, SDL3_image, and SDL3_ttf are correctly configured.

4. Build and run the project.
